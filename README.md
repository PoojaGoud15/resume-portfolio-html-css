Resume Portfolio Webpage

A personal resume webpage built using HTML and CSS to practice frontend layout design, typography, responsive design, and interactive webpage elements.

Features
Personal portfolio-style resume layout
Clean and structured webpage design
Responsive user interface
Professional typography and spacing
Clickable LinkedIn, GitHub, and Email links
Interactive contact section with external navigation
Organized sections for skills, education, and contact details
Technologies Used
HTML5
CSS3
Project Purpose

This project was created to improve my understanding of webpage structure, frontend styling, responsive layouts, alignment, and interactive portfolio website development using HTML and CSS.
